# Lovers Zone — Admin Dashboard

The admin panel for the [Lovers Zone anonymous chat platform](https://github.com/Davetechinnovation/Lovers-Zone-Anonymous-Chat) — user oversight, message moderation and platform monitoring in one place.

**Live:** [lovers-zone-anonymous-chat-admin.vercel.app](https://lovers-zone-anonymous-chat-admin.vercel.app)

## Tech Stack

| Layer | Tech |
|---|---|
| Frontend | React, Vite, Tailwind CSS |
| Backend | Firebase (Firestore) |
| Hosting | Vercel |

## Run It Locally

```bash
npm install
npm run dev
```

You will need your own Firebase project credentials for the app to connect.
